# Demo: sistema de turnos para peluquerías

- `index.html`: página del local con precios, trabajos y reserva online (sin confirmar por WhatsApp: el horario queda tomado al instante).
- `panel.html`: panel del peluquero. Agenda por día, interruptor para abrir o cerrar cada día, cancelación de todos los turnos de un día y aviso por WhatsApp a cada cliente.
- `negocio.js`: lo único que se cambia para cada cliente.
- Modo demo: los datos se guardan en el dispositivo. Para el modo real, ver `SETUP-FIREBASE.md`.
